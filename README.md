# AP-BF-TeleApp

Telegram Mini App and bot for the zone **Building Fund** campaign (to Feb 2027):
financial accountability, spiritual tracking and gamified engagement.

| Phase | Scope                                   | Status  |
|-------|-----------------------------------------|---------|
| 1     | Architecture & database (Prisma schema) | ✅ done |
| 2     | Express server + `initData` HMAC validation | ⏳     |
| 3     | Bot, `/start` Web App button, Monday 05:00 SGT cron | ⏳ |
| 4     | React + Telegram SDK setup, 5-tab routing | ⏳    |
| 5     | Leaderboard + Admin Dashboard UI        | ⏳      |

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the design and how to run it locally.
